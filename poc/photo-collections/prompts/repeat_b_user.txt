## 这组照片
这是同一个人在很多个不同的日子里反复拍的一类东西，不是同一天的一件事。
- 主题：{theme_name}（短名词：{noun}）
- 每次都一样的是：{same_part}
- 月份：{months}；集中在：{where}
- 共 {k} 张，按时间排好，大多来自不同的日子；标「封面」的那张会出现在锁屏上
=====PHOTO=====
{id}｜{date} {time}{cover}｜描述：{description}｜人数：{people}
=====TASK=====
## 第一步：认出这组反复的是什么

scene：用一句话说这组照片反复拍的是什么。换成一个普通人，会怎么跟朋友讲这件事？比如「路过书店看一眼橱窗」「阳台上的多肉」「晚上去球场打球」「家里的晚饭」「路上遇到的猫」。
- 短短一句，10 个字上下，只写一眼看得出来的那件事和大概在做什么。不猜心情，不猜和谁一起，不猜东西是谁的、地方是谁家的，不猜照片里没有的事。
- 这一句只给你自己用，不会给用户看。下面的细节句和问题都从这里出发。

## 任务一：写 3–5 句细节句

写法：先说这组反复拍的是什么，再最多点一样最显眼、这些照片里大多都有的东西；可以留半步余味（光、时间、那一刻），不落在心情。不列举这几次哪里不一样，也不报次数。
- 像一个人自己发的一条配文：用平常说话的词，具体，不绕弯。念出来要像正常人会说的话；拿不准就写得更平常一点。
- 看点：写这些照片里大多都有、人会记得的那样东西（一盆多肉、球场的灯、书店的橱窗）。最多点一样。不写没人记得的小物件，不堆颜色、材质、部位。
- 风格跟着主题走：每句从「诗意、轻松、俏皮、自然」里选一个，写进 style；几句可以是同一种风格。诗意不用强行写：只有画面本身就有意境（晚霞、夜色、雨里的灯）时才用，写不自然就换成轻松或自然。吃饭、室内、有人、动物的场面多半用轻松或自然。
- 排序：你觉得最配这个主题的那句排第一。
- 长度跟着意思走：说完就停，不为凑字数加修饰，也不刻意压短，一般 12–18 个字。一句只写一个画面，多数是一到两小句；想写的东西多，就分成两句候选，不要塞进一句。
- 写完每句数一数（数字、字母、标点各算一个字）：超过 18 个字，就删掉一样东西或一个修饰，不要把每个词都压缩。22 个字是程序的硬上限，超过的会被直接去掉，用户就看不到了。句末不加句号。
- 口吻：多数不用主语；也可以用「我」，像自己发的一条配文。「你」后面只接「拍了」「拍下」。
- 可以猜的（无害）：这是什么场面（路过书店看橱窗、晚上去球场打球）；大概在做什么（散步、吃饭、下班路上）；玩笑式的拟人。
- 不能猜的（会伤人）：心情（开心、温馨、幸福……）；人和人的关系；东西是谁的、地方是谁家的（不写「邻居」「朋友家」）；敏感的事（生日、约会、婚礼……照片里写着的除外）。
- 照片里没有的东西不写。比喻和拟人可以用，但：被比的东西必须在照片里；不拿人打比方，不借比喻说心情；一句最多一个，不夸张。
- 人：能不写就不写。非写不可，只用「有人」「两个人」「一群人」，不用「男子、女子、男人、女人、小孩」，不写是谁、什么表情。
- 和封面的关系：写的是这个主题就算对得上，不必点名封面上的某样东西。
- 不写空泛的夸（好看、绝美……），不写闻到、尝到、听到的，不用「时光」「回忆」。
- 大忌：不写会让人往死、病、受伤、离开、出事上想的话。写动物和人时尤其小心：不写「一动不动」「不动了」「没动静」「睡着不醒」「闭上眼」「最后一次」这一类，哪怕照片里它真的在睡。
- 重复主题另外不能写的：
  - 把不同的几次说成同一个：不写「同一个」「同一只」「又是」「还是那」（同一只碗、又是那片天、还是那家店）。这些照片是不同的日子拍的，东西和地方不一定是同一个。
  - 评判习惯：不写「总是」「坚持」「爱拍」「又」。
  - 报次数或频率：不写「拍了几次」「几次」「每天」「天天」，也不写具体的次数。
  - 写成合集说明（「这是你的晚霞合集」）。
  - 只写某一次：只有某一天、某一张里才有的事不写（某一张里飞过的一只鸟、某一天的雨）。
- photo_ids 写这句用到的照片编号：写的是每次都有的那一刻，就写最能看出这一刻的几张。照片编号（P1、P2……）和「封面」两个字只是给你看的标记：编号只写进 photo_ids，这两样都不要写进句子。
- 照片太普通、实在写不出来时，cannot_write 为 true。

写完念一遍：读着顺不顺？有没有搭不上的词、硬凑的句子？换到这组里的任何一张，这句话还成立吗？
- 诗意的句子，要像一篇好散文、一句好歌词里的一句：可以讲究，但每个词都站得住；
- 轻松、俏皮、自然的句子，要像一个人会发在朋友圈里的话。

好的例子（只是示范写法，不要照抄：换成这组照片里真有的东西）：
- 阳台的多肉，挤满了一个盆（自然）
- 路过书店，看一眼橱窗（自然）
- 球场的灯一亮，就有人来打球了（轻松）
- 多肉们晒着太阳，一盆比一盆胖（俏皮）
- 雨伞撑开，街上的灯映在水里（诗意）
- 地铁站那面墙，画满了涂鸦（自然）

不好的例子（原因 → 可以怎么写）：
- ✗ 又是那盆多肉，摆在同一个窗台上（把几次说成同一个）→ ✓ 阳台的多肉，挤满了一个盆
- ✗ 你总是路过书店就停下来拍（评判习惯）→ ✓ 路过书店，看一眼橱窗
- ✗ 拍了 23 次的球场（报次数）
- ✗ 这是你的球场合集（写成合集说明）
- ✗ 九月那天的球场上，飞过一只鸟（只写了某一次）
- ✗ 绿的、粉的、紫的，七盆多肉七种颜色（列举这几次哪里不一样）
- ✗ 灯光陪着度过每一个温馨的夜晚（写心情）
- ✗ 灯光落下来，它们就趴在那儿不动了（让人以为它出事了，大忌）→ ✓ 换着地方睡，哪儿软去哪儿
- ✗ 天刚烧起来，路灯就亮了（「烧起来」不是平常人的说法）→ ✓ 晚霞还没散，路灯先亮了
- ✗ 一回头，正好撞进镜头里的慵懒（硬凑，读着别扭）→ ✓ 一回头，正好看着镜头
- ✗ 烤肠切面泛油光，绿豆与薯条在托盘里堆成小山（把东西一样样堆上去，像外卖详情页）→ ✓ 一托盘烤肉，配豆角和薯条，那晚的油纸很满
- ✗ 猪脚饭与冬阴功并排，木桌盛满弗里斯科的夜晚（硬凑诗意，「木桌盛满夜晚」搭不上）→ ✓ 猪脚饭配冬阴功，一个周五的晚上
- ✗ 不锈钢杯底剩着汤痕，蓝色杯盖静静躺在木纹旁（没人会记得的小物件）→ ✓ 一根玉米，一盒便当，一个周四的中午
- ✗ 浅灰色联排住宅的门牌号，被头顶未散的晚霞照亮（门牌号没人记得）→ ✓ 晚霞还没散，一排房子亮了灯
- ✗ 舞台前站着几个人影，话筒对着镜头（人看得很清楚却写「人影」，像监控）→ ✓ 天色暗下去，台上的光亮起来
- ✗ 桌上摆着两大托盘肉，油纸贴着价签（结尾落在价签这种小物件上）→ ✓ 去掉价签，只留那一桌肉
- ✗ 台阶蓝漆泛光，像通往夜晚深处的路（写的是漆面，不是那晚的事；后半句鸡汤）→ ✓ 写那晚去看演出这件事，不写漆面
- ✗ 菜单展开，木质桌面承托着未点的期待（鸡汤）
- ✗ 汤锅立在橙红汤里，蘸料杯映着微光（读不通）
- ✗ 邻居们为了吓我，真的很努力（猜了「邻居」：不知道是谁家）
- ✗ 小鬼当家，路人负责哇（替用户做了反应）
- ✗ 跟着人流走上了舞台（编了「走上舞台」：拍照的人在台下）
- ✗ 和朋友度过的温馨夜晚（猜关系，写心情）

## 任务二：出 3 个问题

问题要让人说出照片拍不到的那部分。总原则：**问人事后还记得、愿意聊的那部分，不问你从照片里「找」出来的、拍照那一秒的物理细节。**
- 开放着问：问「什么、哪一、怎么、为什么、去哪儿」，不问「是不是、还是、……吗」，也不问「够不够、多不多、值不值」：答一个字就没话了。一个问题只问一件事：问号前面不要再接「还是……」。
- 围着第一步认出的这件事问：每次都一样的那一刻在做什么、第一反应是什么、从什么时候开始、这些次里哪一次最……、下次想怎样。点名东西，只点这组里最显眼的那一样（多肉、球场的灯），不点角落里的小物件。
- 不猜「是谁」：拍照的人在镜头后面。不假设照片里的人是用户，不假设东西是谁的、地方是谁家的。照片里的人用「有人」「大家」；「你」只指拍照的人。答不上来的不问。
- 问完就停，不加铺垫。一般 10–16 个字，最多 22 个字（超过 22 个字的问题会被改短一次，还长就去掉）。
- 不问：东西的型号、材质、做法；答案在照片里就看得到的（招牌上写的字、盘子里摆的菜）；为什么拍这张、怎么决定拍的。
- 一个词、一句话就能答，靠回忆就能答上来。
- 不问心情（不问「开心吗」），不假设那天很好；照片里没有人，就不假设有人陪；不问关系，不用他、她；不用「如果当时」；不和别人比；不提分享、发给谁。
- 重复主题另外不能问的：不评判习惯、不报次数（不问「为什么总拍」「你每天都……」）；不假设它对用户有特别的意义（不问「它对你意味着什么」）；不把不同的几次说成同一个；不只问某一次（这组是很多次，不问「那个傍晚」）。
- 不用「又、一直没、好久没、别忘了、该、错过、再也、还没」，也不用「总是、坚持、爱拍、每天、天天」。
- 不写照片编号（P1、P2……），也不写「封面」两个字。
- 每个问题从下面的类型里选一个 type：
{type_table}
- 尽量避开这些类型（前后几晚已经用过）：{recent_types}
- 三个问题尽量不同类型，但不要为了换类型凑一个没人在意的问题。按贴切程度排好，普通人最想回答的排第一；why 一句话说明为什么贴切。
- 写完每个问题，自问一句：普通人看到这个问题，会想回答，还是会觉得「这有什么好问的」？是后者就换一个。

好的例子（只是示范问法，不要照抄：换成这组照片里真有的东西）：
- 这些照片里，哪一盆最先想起来？（which_most）
- 看完球赛，一般接着去哪儿？（route）
- 下一盆，想养什么？（next_time）
- 拍它的时候，手里一般在忙什么？（hands_busy）

不好的例子（原因 → 可以怎么问）：
- ✗ 为什么总拍多肉？（评判习惯）→ ✓ 这些照片里，哪一盆最先想起来？
- ✗ 你每天都会去球场吗？（报频率，也是是非题）→ ✓ 看完球赛，一般接着去哪儿？
- ✗ 多肉对你意味着什么？（假设它有特别的意义）→ ✓ 下一盆，想养什么？
- ✗ 那个晚上，你是在去哪儿的路上？（只问了某一次）→ ✓ 看完球赛，一般接着去哪儿？
- ✗ 多肉是粉的好看还是绿的好看？（二选一）
- ✗ 那天你开心吗？（问心情）

## 输出
只输出一个 JSON 对象：scene（一句话：这组反复的是什么）、cannot_write、candidates（每句的 text、style、photo_ids）、question.ranked（3 个问题，按贴切程度排好，每个的 text、type、why）。
