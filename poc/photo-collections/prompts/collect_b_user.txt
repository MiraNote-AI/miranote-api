## 第一步：认出场面

scene：用一句话说这组照片是什么场面。换成一个普通人，事后会怎么跟朋友讲这件事？比如「晚上在街区看万圣节装饰」「下馆子吃泰国菜」「看了一场小演出」「中午排队买饭」「傍晚出门散步，看了晚霞」。
- 短短一句，10 个字上下，只写一眼看得出来的场面和大概在做什么。不写为什么来、不写先后经过、不写店名楼名；不猜心情，不猜和谁一起，不猜东西是谁的、地方是谁家的，不猜照片里没有的事（免费、领东西、上台）。
- 这一句只给你自己用，不会给用户看。下面的细节句和问题都从这个场面出发。

## 任务一：写 3–5 句细节句

写法：先说这个场面，再最多点一样最显眼、人事后会记得的东西。
- 看点：写人事后会记得的那件事（一桌泰国菜、一院子万圣节装饰、台上亮起的灯、天边的晚霞）。最多点一样最显眼的东西。不写没人记得的小物件（门牌号、杯盖、汤痕、蘸料杯），不堆颜色、材质、部位（金属托盘、不锈钢杯底、切面泛油光）。
- 风格跟着场面走：3–5 句的风格各不相同，每句从「诗意、轻松、俏皮、自然」里选一个，写进 style。晚霞、夜色、风景多半适合诗意；万圣节、玩乐、好玩的东西多半适合俏皮；吃饭、日常多半适合轻松或自然。诗意不是每句都要有：吃饭、室内、有人的场面硬造诗意，就会写出「木桌盛满夜晚」这种句子。
- 排序：你觉得最配这组场面的那句排第一。
- 长度跟着意思走：说完就停，不为凑字数加修饰，也不刻意压短，一般 12–18 个字。一句只写一个画面，多数是一到两小句；想写的东西多，就分成两句候选，不要塞进一句。
- 写完每句数一数（数字、字母、标点各算一个字）：超过 18 个字，就删掉一样东西或一个修饰，不要把每个词都压缩。22 个字是程序的硬上限，超过的会被直接去掉，用户就看不到了。句末不加句号。
- 口吻：多数不用主语；也可以用「我」，像自己发的一条配文（今晚出门，认识了一些阴间朋友）。「你」后面只接「拍了」「拍下」。
- 可以猜的（无害）：这是什么场面（万圣节装饰、一桌泰国菜、一场演出、排队买午饭）；大概在做什么（散步、吃饭、逛街）；玩笑式的拟人（阴间朋友）。节日只在一眼看得出装饰时写。
- 不能猜的（会伤人）：心情（开心、温馨、幸福……）；人和人的关系；东西是谁的、地方是谁家的（不写「邻居」「朋友家」）；敏感的事（生日、约会、婚礼……照片里写着的除外）。
- 照片里没有的东西不写。比喻和拟人可以用，但：被比的东西必须在照片里；不拿人打比方，不借比喻说心情；一句最多一个，不夸张。
- 人：能不写就不写。非写不可，只用「有人」「两个人」「一群人」，不用「男子、女子、男人、女人、小孩」，不写是谁、什么表情。人看得清时，不要写成「人影」。
- 和封面对得上：3–5 句都写封面所在的这个场面，别的照片只能当陪衬（写到别的场面的句子用不上）。封面是这个场面的一部分就算对得上，不必点名封面上的某样东西（「散个步，误入一部恐怖片的片场」配一院子装饰的封面，算对得上）；写的是另一个场面就对不上（封面是一幅地画，句子写的却是另一张里的晚霞）。
- 不写空泛的夸（好看、绝美……），不写闻到、尝到、听到的，不用「时光」「回忆」。
- photo_ids 写这句用到的照片编号。照片编号（P1、P2……）和「封面」两个字只是给你看的标记：编号只写进 photo_ids，这两样都不要写进句子。
- 照片太普通、实在写不出来时，cannot_write 为 true。

写完念一遍：读着顺不顺？有没有搭不上的词、硬凑的句子？
- 诗意的句子，要像一篇好散文、一句好歌词里的一句：可以讲究，但每个词都站得住；
- 轻松、俏皮、自然的句子，要像一个人会发在朋友圈里的话。

好的例子（只是示范写法，不要照抄：换成这组照片里真有的东西）：
- 天色暗下去，台上的光亮起来（诗意）
- 晚霞还没散，一排房子亮了灯（诗意）
- 天边粉了，人行道上裂开一道峡谷（诗意）
- 夜色借了鬼怪的脸，偷偷热闹（诗意）
- 今晚出门，认识了一些阴间朋友（轻松）
- 散个步，误入一部恐怖片的片场（自然）
- 一托盘烤肉，配豆角和薯条，那晚的油纸很满（轻松）
- 猪脚饭配冬阴功，一个周五的晚上（自然）
- 白帐篷下排着队，一个周四的中午（自然）
- 一根玉米，一盒便当，一个周四的中午（自然）

不好的例子（原因 → 可以怎么写）：
- ✗ 烤肠切面泛油光，绿豆与薯条在托盘里堆成小山（把东西一样样堆上去，像外卖详情页）→ ✓ 一托盘烤肉，配豆角和薯条，那晚的油纸很满
- ✗ 猪脚饭与冬阴功并排，木桌盛满弗里斯科的夜晚（硬凑诗意，「木桌盛满夜晚」搭不上）→ ✓ 猪脚饭配冬阴功，一个周五的晚上
- ✗ 不锈钢杯底剩着汤痕，蓝色杯盖静静躺在木纹旁（没人会记得的小物件）→ ✓ 一根玉米，一盒便当，一个周四的中午
- ✗ 浅灰色联排住宅的门牌号，被头顶未散的晚霞照亮（门牌号没人记得）→ ✓ 晚霞还没散，一排房子亮了灯
- ✗ 舞台前站着几个人影，话筒对着镜头（人看得很清楚却写「人影」，像监控）→ ✓ 天色暗下去，台上的光亮起来
- ✗ 桌上摆着两大托盘肉，油纸贴着价签（结尾落在价签这种小物件上）→ ✓ 去掉价签，只留那一桌肉
- ✗ 台阶蓝漆泛光，像通往夜晚深处的路（写的是漆面，不是那晚的事；后半句鸡汤）→ ✓ 写那晚去看演出这件事，不写漆面
- ✗ 菜单展开，木质桌面承托着未点的期待（鸡汤）
- ✗ 汤锅立在橙红汤里，蘸料杯映着微光（读不通）
- ✗ 邻居们为了吓我，真的很努力（猜了「邻居」：不知道是谁家）→ ✓ 散个步，误入一部恐怖片的片场
- ✗ 小鬼当家，路人负责哇（替用户做了反应）→ ✓ 今晚出门，认识了一些阴间朋友
- ✗ 跟着人流走上了舞台（编了「走上舞台」：拍照的人在台下）
- ✗ 和朋友度过的温馨夜晚（猜关系，写心情）

## 任务二：出 3 个问题

问题要让人说出照片拍不到的「前后」。总原则：**问人事后还记得、愿意聊的那部分，不问你从照片里「找」出来的、拍照那一秒的物理细节。**
- 开放着问：问「什么、哪一、怎么、为什么、去哪儿」，不问「是不是、还是、……吗」，也不问「够不够、多不多、值不值」：答一个字就没话了。一个问题只问一件事：问号前面不要再接「还是……」。
- 围着第一步认出的场面问：问那件事，发生了什么、有人说了什么、东西味道怎么样、为什么来这儿、后来去了哪儿、印象最深的一刻。点名东西，只点这个场面里最显眼的一样（卤猪脚、冬阴功、一院子装饰），不点角落里的小物件（牌子上的小字、一个假人、汤里的豆子）。日常的一份便当、路边的普通街景，本身没什么好问的。
- 不猜「是谁」：拍照的人在镜头后面。不假设照片里的人是用户（不写「你手里握着麦克风」），不假设东西是谁的、地方是谁家的。照片里的人用「台上的人」「有人」「大家」；「你」只指拍照的人。答不上来的（「是哪家布置的」）不问。
- 问完就停，不加铺垫：点到一样东西就够，不用把颜色、位置、从哪儿到哪儿都写进去。一般 10–16 个字，最多 22 个字（超过 22 个字的问题会被改短一次，还长就去掉）。
- 不问：东西的型号、材质、做法（有线还是无线、蒸的还是烤的）；无关紧要的先后（汤先喝还是后喝、先动哪一筷）；环境里的小声响（锅里有没有咕嘟声）；风和光的细节；答案在照片里就看得到的（招牌上写的字、盘子里摆的菜）；为什么拍这张、怎么决定拍的。
- 「去向、来路」只在这组照片真的走了一段路、换了地方时问，问有意义的地方之间（从白沙走到红峡谷），不问普通的路，也不问走了多久、从哪条街来。
- 「哪一样最先吃完」只用在一桌好几样菜上；一份便当、一份饭配一个蛋，不问先后。
- 「声音」只在有演出、有人讲话时问台上说了什么、唱了什么；不问路人说没说话，不问声音清不清楚。
- 「有人在场」只在照片里是一起的人（合照、同桌吃饭）时问；台上的表演者、路人不算。
- 一个词、一句话就能答，靠回忆就能答上来。
- 不问心情（不问「开心吗」），不假设那天很好；照片里没有人，就不假设有人陪；不问关系，不用他、她；不用「如果当时」；不和别人比；不提分享、发给谁。
- 不用「又、一直没、好久没、别忘了、该、错过、再也、还没」。
- 不写照片编号（P1、P2……），也不写「封面」两个字。
- 每个问题从下面的类型里选一个 type：
{type_table}
- 尽量避开这些类型（前后几晚已经用过）：{recent_types}
- 三个问题尽量不同类型，但不要为了换类型凑一个没人在意的问题：宁可两个问题都围着同一个场面问。按贴切程度排好，普通人最想回答的排第一；why 一句话说明为什么贴切。
- 写完每个问题，自问一句：普通人看到这个问题，会想回答，还是会觉得「这有什么好问的」？是后者就换一个。问题里有「还是」「吗」「够不够」「多不多」，就改成用「什么、哪一、怎么」来问。

好的例子（只是示范问法，不要照抄：换成这组照片里真有的东西和时刻，「那桌菜」只用在一桌菜上，「去哪儿的路上」只用在路上拍的照片）：
- 从白沙走到红峡谷，中间经过了哪条路？（route）
- 那桌菜里，哪一样最先吃完？（order）
- 这家店，是怎么找到的？（found）
- 那个傍晚，你是在去哪儿的路上？（route）
- 那晚台上说的话，你还记得哪一句？（sound）
- 这一路的万圣节装饰，哪一家最吓人？（other）
- 看完这一路装饰，后来去了哪儿？（route）
- 那锅冬阴功，味道怎么样？（taste）

不好的例子（原因 → 可以怎么问）：
- ✗ 那锅冬阴功火锅，喝起来是酸还是辣？（二选一：答一个字就没话了）→ ✓ 那锅冬阴功，味道怎么样？
- ✗ 便当里的肉片蔬菜，味道咸淡合适吗？（是非题）→ ✓ 那顿午饭，哪一口最好吃？
- ✗ 那锅冬阴功，味道够不够正宗？（是非题）→ ✓ 那锅冬阴功，味道怎么样？
- ✗ 那排长队，是在等吃还是等拿东西？（二选一）→ ✓ 帐篷下的队，是在等什么？
- ✗ 这家店是怎么找到的，还是路过碰巧进的？（后面又接了一个二选一）→ ✓ 这家店，是怎么找到的？
- ✗ 那幅地画，是在哪条街找到的？（问街名没人在意，答一个地名就没话了）→ ✓ 那幅地画，是怎么遇到的？
- ✗ 掘墓人手写牌子上，多埋十美元是真的吗？（盯小物件）→ ✓ 这一路的万圣节装饰，哪一家最吓人？
- ✗ 台上那阵子，你手里握着麦克风说了什么？（把台上的人当成了你）→ ✓ 那晚台上说的话，你还记得哪一句？
- ✗ 那排骷髅头，是哪家布置的？（答不上来）
- ✗ 从外面的街道走到这个舞台，中间经过了哪段路？（铺垫太长，路也普通）
- ✗ 带便当是为对比免费餐吗？（猜原因）
- ✗ 台上那人的麦克风，握的是有线还是无线？（问物件型号：没人在意，也答不上来）
- ✗ 在芒草夕阳那组问「那桌菜里，哪一样最先吃完？」（套话，和这组照片对不上）
- ✗ 那天你开心吗？（问心情）
- ✗ 和朋友一起吃饭是什么感觉？（假设有人陪、猜关系）

## 输出
只输出一个 JSON 对象：scene（一句话）、cannot_write、candidates（每句的 text、style、photo_ids）、question.ranked（3 个问题，按贴切程度排好，每个的 text、type、why）。
